# 隐私说明 · WeType Quick

[繁體中文](../PRIVACY.md) · 简体中文 · [English](PRIVACY.en.md)

审查日期：2026-10-05。本说明涵盖公开源代码／本机补丁的速成代码，以 Q5r2 为基础，另加入会话缓存清理。
这是源代码和静态审查，不是整个腾讯微信输入法的端到端审计，也不是隐私保证。

## 最重要的限制

新增字词查询和学习代码没有网络客户端，但本机修改后的键盘仍包含原版专有 App，
包括网络、云端语音、上报、剪贴板和词典相关功能。这些功能没有被全面审计或移除。
不能宣称整个 App 完全离线、不上传、匿名或适合所有敏感输入。
本机打补丁仅避免在此分发原 APK，并未隔离新增代码和原版，也没有移除原版权限。

## 新增速成代码保存什么

- `quick-learning.bin`：速成码／查询、明确选中的字词、选择次数和相对最近使用序号。
  这些记录可能反映你输入过的字词，没有加密，也不是匿名数据。格式不包含实际时间戳、
  App／账户标识或前后文消息内容。
- 最多 4,096 条单字和 4,096 条词语记录，词语最多八字；超出各自上限时淘汰最久未选的记录。
  文件上限 1 MiB。
- `quick-native-actions.bin`：你明确置顶／隐藏候选的选择，包括查询、候选文本和操作。
  最多共 4,096 条、1 MiB，不额外保存选择次数或时间戳。
- 两文件存于 App 私有的 `getNoBackupFilesDir()`，Android Auto Backup 排除此目录。
  这不能防止原版 App 自身、特权／root 访问、手动复制、设备被入侵或每种数据迁移机制。
  参见 [Android 备份文档](https://developer.android.com/identity/data/autobackup)。
- 写入采用校验码、临时 `.new` 和恢复 `.bak` 文件。校验码仅检查损坏，不是加密或防篡改认证。
  成功保存会删除旧备份，失败或中断可能留下恢复文件。
- 是否选用速成，另以布尔值保存在 App 私有 shared preferences `quick-native-backend`。
- 没有按时间自动删除的期限；记录保留至清除、淘汰或移除 App 数据。进入私人字段不会删除旧记录。

## 何时学习，何时不学习

普通受支持文本框内，明确选字且编辑器接受提交后会自动学习，目前没有独立的全局“停用学习”开关。
仅查询、取消组字、提交失败以及收起键盘时自动结算，不新增选择记录。

非文本类型及识别出的密码、可见密码、网页密码字段会停用速成。网址、邮箱、网页邮箱字段，
或编辑器提供 `IME_FLAG_NO_PERSONALIZED_LEARNING` 时，会抑制速成学习、个性化排序和置顶／隐藏操作。
缺少编辑器信息时保守处理。参见 [Android 编辑器标记文档](https://developer.android.com/reference/android/view/inputmethod/EditorInfo#IME_FLAG_NO_PERSONALIZED_LEARNING)。

引擎在进程内存中缓存最近的查询／候选计划。本源代码版本在进入或再次指定私人模式时，
会解除该计划的引用，包括原本已是私人模式的会话结束／开始边界；原有学习记录不受影响。
没有发现此缓存写入磁盘、日志或网络的路径。解除引用不是覆盖或取证级内存擦除，
不保证 Java 垃圾回收的时间，也不涵盖原版或其他对象可能持有的数据。

这些仅是新增速成层的保护，依赖使用中的 App 正确标记输入字段；不是通用无痕模式检测，
也不保证原版行为。键盘仍需处理文字，才能输入目标 App。

## 清除及旧记录

原版个人词典清除／重置指令已连接至两类速成记录，包括速成尚未初始化时。
成功清除会写入空白配置并删除旧恢复数据；I/O 失败会提示清除未完成，请重试，不要假定已删除。
这不代表清除原版全部缓存、剪贴板记录或服务器数据，也不是取证级安全擦除。

学习读取器兼容旧 v1 和当前 v2 本地格式，之后保存为 v2，不是网络迁移。
学习文件不可读时会警告并退回内存模式；原有损坏文件可能仍留在磁盘，直到明确清除。
候选操作文件不可读时，相关操作会停用直到成功重置。

## 删除时读取的上下文

光标前清除的安全检查最多请求光标前 2,048、后 32 个 UTF-16 单元，避免不安全的字素边界删除，
并读取选择位置元数据。备用 extracted-text 请求提示仅需一字，但 Android 提示不是硬性上限，
编辑器可能返回更多；新增代码检查返回的元数据／长度，不复制正文。
该规划器不保存、记录或上传上下文，仅返回位置、数量和固定诊断原因。
这只描述新增规划器，不涵盖原版全部上下文处理。

## 候选上报和语音

固定版本的补丁在速成拥有组字状态或出现速成候选标记（包括过期标记）时，抑制已识别的原生候选上报入口。
这是针对性保护，不是关闭全部原版遥测；原有生命周期回调、非速成上报、网络及其他路径仍在。

麦克风辅助代码仅向指定原版语音录音器请求手机内置麦克风，之后恢复原偏好。
它不读取 PCM 样本、不自行启动录音、不更换语音服务商，也不添加音频上传器。
新增日志仅包含固定路由状态／错误文字，不记录音频、输入文本、设备名称、地址或设备标识。

原版有语音数据请求／上报路径，语音输入可能向原服务商发送音频及相关数据。
此次审查未确立实际连接目的地、保留期限、同意流程或服务器处理方式。
改变 APK 签名也可能令原语音服务不可用。切换麦克风偏好不会令识别变为离线，也不会绕过检查。

## 权限与原版风险

原版 manifest 保留 INTERNET、RECORD_AUDIO，以及网络／Wi-Fi 状态、蓝牙、SMS、相机、存储、
旧 Android 位置、附近 Wi-Fi、通知、悬浮层和软件包安装相关声明。
声明不等于 Android 已授权，也不证明数据曾被收集。剪贴板功能仍在；没有独立剪贴板权限不代表键盘无法访问。

原版网络安全配置允许明文流量，这是潜在传输风险，不是特定请求使用明文的证据。
上报／崩溃组件、语音消息、云词典、剪贴板和原版更新组件均保留；实际行为及传输内容不在此次审计范围。

主工具下载器从所列上游 HTTPS 来源获取固定 SHA-256 的开发工具。可选主机测试使用 Maven，
本仓库未对全部传递依赖逐一固定独立校验码。下载服务可见一般连接信息。
这些脚本不上传 APK 或键盘记录；构建生成本地未签名 APK，不安装、启动或签名它。

新增项目没有到期限制、支付验证、许可服务器、新增统计或自动更新器；原版更新代码仍保留。

请勿在公开问题中上传原版／修改版 APK、私钥、凭证、个人词典、输入内容、音频或未脱敏日志。
只分享最小的虚构数据复现；敏感发现应使用已核实的私人反馈渠道。

## 验证限制与下一步

源代码和模拟测试涵盖存储、私人字段、清除、候选保护和路由状态。框架测试使用自行编写的主机替身，
不执行完整原 App。本次未使用真实用户文字／音频、实时网络抓包或实机隐私测试。
原生库、远程服务、全部原版数据流和 Android／厂商行为仍未全面审计。

在推荐用于敏感日常输入前，应在隔离测试配置使用虚构文字／音频，检查网络、同意／设置变化、
实机删除、原版更新和签名来源。独立停用学习开关可以进一步改善用户选择。
这些只是建议，不是已完成功能或通过的测试。
