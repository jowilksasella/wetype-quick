# WeType Quick · 非官方速成补丁

[繁體中文](../README.md) · 简体中文 · [English](README.en.md)

为 Android 微信输入法加入香港常用速成输入的实验性源代码和补丁工具。
新增引擎提供繁体字词、连续输入、本机排序，以及原版键盘界面的适配。

本项目非官方，与腾讯／微信输入法没有隶属或背书关系。开源许可仅适用于
本仓库自行编写的代码及各自许可的第三方数据，不涵盖原版程序、商标、素材或语音服务。

> v0.1.0 是本项目的首个源代码版本；支持的原版微信输入法版本为 3.5.4。
> 发布内容不含原版或修改版 APK。你须自行取得有权使用的指定原版，在本机重建。

## 功能

- 仓颉首尾码速成，17,213 个字、100,032 个繁体／粤语词
- 最多连续输入 8 字／16 根，可用分词键明确分段
- 适配原版中文全键盘、候选栏、展开字表和键盘选择器
- 字根显示于键盘上方的组字区，选字后才提交到文本框
- 单字筛选、分组加载候选；长按可本机置顶、取消置顶或隐藏候选
- 本机选字学习，按照有效输入框的密码／禁止个性化规则停用学习
- 原版“清除个人词典”同步清除速成记录
- 蓝牙耳机已连接时，向该次语音录音器提出手机内置麦克风偏好

字形与候选顺序不保证与 Gboard 或其他速成输入法一致。

## 兼容性

- 只接受原版 **3.5.4**，224,668,031 bytes
- 原版 SHA-256：`c036f49444b3230fc2fc7c119ae79f32b33766374fd5dc6d48246dea378ff889`
- 本机输出标识为 `3.5.4-quick.0.1.0`，versionCode 57207，并非新的腾讯官方版本
- 新增 DEX 最低目标 API 24，不保证所有 Android 7+ 设备兼容
- 其他版本、拆分 APK、重新打包的原版均会因哈希不符而拒绝构建

## 本机构建

需要 Python 3.10+、Java 21、curl 和足够的存储空间。Linux 已测试；Windows／macOS 尚未实测。
工具从官方项目／Maven 下载，按固定 SHA-256 验证；不会下载原版 APK。
首次获取工具和测试依赖需要网络。

```sh
python3 scripts/build_local.py /absolute/path/to/original-3.5.4.apk
```

Windows 原生可尝试 `py -3 scripts/build_local.py "C:\path\original-3.5.4.apk"`；尚未在 Windows 验证，不需要 WSL。

输出：`.local/build/wetype-quick-0.1.0-local-unsigned.apk`，附本机结构检查报告。
构建工具不会安装、执行、上传或签署 App，也不会生成或保存签名密钥。
高级测试、签名和安装见 [BUILD.md](BUILD.md)。请勿绕过版本／哈希检查。
修改、使用和分发可能受当地法律及原版条款限制。只发布补丁不等于自动获得相关权利。

## 安装与使用

1. 阅读 [构建、签名和安装说明](BUILD.md)，自行保管签名密钥。
2. 用 Android 系统安装自行签名的本机产物，在系统输入法设置中启用。
3. 在原版键盘／输入方式选择页选“速成”，选择其他模式即可返回原版后端。
4. 输入 `enym`（水弓卜一），候选包括“測試”；选字后才写入文本框。

重新签名的 App 无法直接更新腾讯原版，同包名也不能与原版共存。
卸载可能永久删除数据，请先备份，勿为解决签名冲突而盲目卸载。
你的密钥也无法更新使用他人密钥签名的实验版。
